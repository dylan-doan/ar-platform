# {{EVENT_NAME}} — 靜態網站專案

這是「{{EVENT_NAME}}」活動網站的**靜態版**專案。建置後會產生純 HTML / CSS / JS，
**不需要 Node 伺服器**，可以直接上傳到任何虛擬主機（cPanel、Netlify、Vercel、
S3、nginx…）。

---

## 一、建置

```bash
npm install
npm run build      # 產生 ./out 資料夾
```

把 **`out/` 資料夾裡的全部內容**上傳到您的主機根目錄，就完成了。

想先在本機看看：

```bash
npm run serve      # http://localhost:3000
```

---

## 二、改樣式（最常用）

打開 **`app/custom.css`**，寫您的 CSS。這個檔案會在網站樣式之後載入，因此**這裡
的設定優先**；重新從平台匯出專案時**不會覆蓋**它。

網站是用設計變數（design tokens）組成的，所以改變數就會整站一致地改變，通常比
一個一個元素改要好：

```css
:root {
  --site-radius: 0;            /* 卡片圓角（直角） */
  --site-btn-radius: 8px;      /* 按鈕圓角 */
  --site-heading-weight: 900;  /* 標題字重 */
  --text-strong: #111;         /* 標題文字顏色 */
  --surface-sunken: #f5f5f5;   /* 卡片背景 */
}
```

改完再跑一次 `npm run build`。

> **想讓改動也出現在平台的拖曳設計器裡？**
> 請改寫在後台「活動設定 → 全站自訂 CSS」。寫在那裡的 CSS 會跟著設計一起走
> （重新匯出也還在）；寫在 `app/custom.css` 的只存在於這個專案。

## 三、內容怎麼來的

網站內容有**兩層**：

1. **匯出時已內建**（`data/site.json`）— 建置出來的 HTML 裡就有真實的文字和圖片，
   所以搜尋引擎讀得到，關掉 JavaScript 也看得到內容。
2. **瀏覽時即時更新** — 頁面載入後會向平台的公開端點要一次最新內容，若後台有改過
   就自動換成新的。

因此「後台改文字 → 訪客重新整理就看到」是成立的，**不必重新建置**。

平台連不上時會靜靜地維持第 1 層的內容（網站不會壞掉）。

要確認目前顯示的是哪一層：瀏覽器開 DevTools → Elements → 找 `<head>` 裡的
`<meta name="zoustec:source">`：

- `api — GET …` = 即時內容
- `snapshot — …` = 匯出時內建的內容（平台連不上或未設定）

### 沒有 API 金鑰

這個靜態版**不需要也不應該有** API 金鑰。它讀的是匿名公開端點
（`/api/public/site/...`），回傳的就是網站本來就公開顯示的資料（活動名稱、
任務站點名稱、品牌設定），**不含** QR 密鑰或參加者資料。

靜態網站的 JS 是公開的 — 任何放進去的金鑰所有人都看得到，所以我們刻意不放。

`.env.local` 裡的 `NEXT_PUBLIC_*` 值會被編譯進前端 JS，請只放非機密資訊。

## 四、要注意的地方（重要）

**新增的頁面不會自動出現。** 靜態網站的每個網址都是建置時產生的實體檔案。如果您
在後台**新增了子頁面**，這個專案要**重新匯出（或重新建置）**才會有那一頁的檔案；
在那之前選單上的連結會是 404。

已存在頁面的**內容**修改不受影響（見上面第三節），只有「新增／刪除頁面」需要重新
匯出。

如果您的活動會頻繁增減頁面，建議改用**Next.js 版**（在後台匯出時選另一個選項），
那個版本是伺服器渲染，新頁面立刻生效。

## 五、檔案在哪

| 路徑 | 用途 |
|---|---|
| `app/custom.css` | **您的 CSS**（改這裡） |
| `app/page.jsx` | 首頁 |
| `app/[page]/page.jsx` | 子頁面／其他活動頁 |
| `components/event/` | 網站的區塊與版面（與平台完全相同的檔案） |
| `lib/site-live.js` | 即時抓取內容的邏輯 |
| `data/site.json` | 匯出時的內容快照 |
| `.env.local` | 平台網址與租戶代號 |

`components/` 和 `lib/site-blocks.jsx` 是平台正在使用的**同一份檔案**，所以這個
網站的外觀和後台拖曳設計器看到的一致。可以改，但重新匯出時會被覆蓋 —
自訂樣式請寫在 `app/custom.css`。
